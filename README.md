# Build a Personal Information Program

## 1. Project Description
This project is a simple Python program that accepts a user's basic personal information and displays it in a clean, formatted profile.

## 2. Objective
The project demonstrates:
- Variables
- `input()`
- Type conversion
- Formatted output using f-strings

## 3. Technology / Tools
- Python 3
- VS Code / PyCharm / Jupyter Notebook

## 4. Files
- `personal_information.py` – Python source code
- `sample_output.txt` – Sample program execution
- `README.md` – Project documentation
- `project_report.pdf` – Complete project report

## 5. Inputs
The program asks the user to enter:
1. Name
2. Age
3. Email
4. Phone number
5. City
6. Course

The age is converted from the string returned by `input()` to an integer using `int()`.

## 6. Output
The entered information is displayed as a clean personal profile.

## 7. How to Run
1. Install Python 3.
2. Open a terminal in the project folder.
3. Run:
   `python personal_information.py`
4. Enter the requested information.

## 8. Sample
Example input:
- Name: Keerthi
- Age: 21
- Email: keerthi@example.com
- Phone: 9876543210
- City: Vijayapura
- Course: Electronics and Communication Engineering

The program then prints the information in profile format.

## 9. Interview Questions and Short Answers

### What is a variable in Python?
A variable is a name used to store or refer to a value.

### What is the difference between input() and print()?
`input()` receives data from the user, while `print()` displays data on the screen.

### What is an f-string?
An f-string is a formatted string that allows variables or expressions to be placed directly inside a string using `{}`.

### Why is type conversion required for user input?
`input()` returns data as a string. Type conversion changes it to a suitable type, such as `int`, when numerical operations are required.
